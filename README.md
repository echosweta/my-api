# FastAPI Users API

A simple REST API built with **FastAPI** and **Python**.

This project was built while learning backend development and API fundamentals, including:

- REST APIs
- HTTP methods
- GET and POST requests
- Path parameters
- Request validation with Pydantic
- JSON data persistence
- CRUD API concepts
- API error handling

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
- JSON
